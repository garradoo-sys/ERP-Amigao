OFICINA360 ERP — PROTÓTIPO COM LOGIN E USUÁRIOS

1. Abra o arquivo index.html no Google Chrome ou Microsoft Edge.
2. Primeiro acesso:
   Usuário: admin
   Senha: admin123
3. Entre em "Usuários e acessos" para cadastrar outros usuários.
4. É possível escolher perfil, permissões, ativar, bloquear, editar e excluir contas.

IMPORTANTE:
Este é um protótipo local. Os dados e as senhas ficam armazenados no navegador.
Para uso comercial, a autenticação deve ser implementada em servidor, com banco de dados,
hash seguro de senha, HTTPS, recuperação de senha e logs de auditoria.
